# miniapp

个人微信小程序的发布知识库，重点沉淀：无营业执照时能注册几个小程序、个人主体开放类目、OPC 应用与业务展示边界、设计最佳实践、上架清单和合规注意事项。

规则核对日期：**2026-11-24**。微信规则更新频繁，实际注册、类目审核、认证和支付能力以微信公众平台后台及官方文档当时显示为准。

## 核心结论

- **无营业执照的个人主体最多注册 5 个小程序**，但不允许注册内容、页面、功能相同或高度同质化的多个小程序。
- 个人主体目前开放 **8 个一级类目**：物流服务、教育服务、生活服务、餐饮服务、旅游服务、工具、商业服务、体育。
- 个人 OPC 的“所有应用和业务”适合做成**个人应用工作台 / 作品与业务介绍**，不适合直接做成聚合第三方应用的“小程序应用市场”。
- 普通微信支付、商城和实物交易不适合作为个人主体的首版范围。2026 年新增的个人虚拟支付有独立条件，不能与普通微信支付混为一谈。
- 首版建议只做 **1 个小程序**，把身份介绍、应用展示、案例、业务说明和联系入口做完整。

## 适用对象

- 以中国大陆个人身份注册微信小程序的开发者。
- 没有营业执照，希望展示个人 OPC、应用、作品、项目或轻量服务的人。
- 正在决定先做一个小程序，还是拆分成多个小程序的个人开发者。

## 维护原则

1. 规则变化时，优先更新完整指南中的事实、日期和官方链接。
2. 区分“平台明确规则”“基于规则的产品建议”“待后台确认事项”，避免把建议写成强制规则。
3. 不提交 AppSecret、支付密钥、身份证件、后台截图中的敏感信息或其他凭证。
4. 上线前重新核对官方类目、备案、认证、支付和审核要求。
